# ninjabuilds-skills

Reusable skills everyone can benefit out of it. Each folder is one skill
that walks an AI assistant through a task step by step, so anyone can get
the same result with their own details.

## Skills

- [apple-app-bundle-registration](apple-app-bundle-registration) — Register
  a new iOS app under an existing Apple Developer Program account: Bundle ID,
  App Store Connect record, and Xcode and Firebase wiring.
- [sheet-dashboard-builder](sheet-dashboard-builder) — Turn any Google
  Sheet of transactions into a live spending dashboard, as a Dashboard tab
  with formulas and charts and optionally a live app that reads the sheet
  on every open.
- [statement-to-spending-sheet](statement-to-spending-sheet) — Turn Bank
  of America eStatement PDFs into a categorized Spending Tracker Google
  Sheet, with every total reconciled to the printed statement totals to
  the cent.

## How to use

Open a skill folder and follow its README. Download `SKILL.md`, install it
in your assistant's skills, and ask for the task in your own words.
